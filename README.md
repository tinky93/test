# Node.js Authentication Project 🔥😎

مشروع تسجيل ودخول بسيط باستخدام Node.js، Express، وMongoDB.

---

## 📂 الملفات

- server.js — ملف السيرفر الرئيسي
- routes/authRoutes.js — مسارات التسجيل والدخول مع Validation
- models/user.js — نموذج المستخدم (User schema)
- index.html — واجهة المستخدم للـ Register و Login
- .env.example — إعدادات البيئة (تضع بيانات MongoDB هنا)
- package.json & package-lock.json — معلومات المشروع والحزم

---

## ⚙️ المتطلبات

- Node.js v18+
- MongoDB (محلي أو Atlas أونلاين)
